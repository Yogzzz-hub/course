# Shared Library (`lib/`)

This directory holds shared type contracts and API route specifications used across the Aintrix Academy platform.

## Contents
* `types/models.ts`: Pure TypeScript interfaces representing database models (Users, Programmes, Batches, ClassSessions, Payments, Submissions, Certificates).
* `contracts/api.ts`: Formal REST API specifications listing all endpoints, HTTP methods, and parameter expectations across all 6 portals.
